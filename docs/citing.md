# Citing

If you use FedGES, please cite:

```bibtex
@article{torrijos2026fedges,
  author = {Torrijos, Pablo and G{\'a}mez, Jos{\'e} A. and Puerta, Jos{\'e} M.},
  title = {{FedGES}: A Federated Learning Approach for {B}ayesian Network Structure Learning},
  journal = {Machine Learning},
  volume = {115},
  number = {1},
  pages = {9},
  year = {2026},
  doi = {10.1007/s10994-025-06939-2}
}
```

and for FedRCD:

> Torrijos, P., Stella, F., Gámez, J.A. & Puerta, J.M. Federated Causal Discovery via Regression-Directed Cumulants. Probabilistic Graphical Models (PGM), 2026.

[`CITATION.cff`](https://github.com/ptorrijos99/fedcausal/blob/main/CITATION.cff) carries both, and GitHub shows it as "Cite this repository". The software itself is archived on [Zenodo](https://doi.org/10.5281/zenodo.24603527) under 10.5281/zenodo.24603527, which resolves to the latest version; every release also has its own DOI. The baselines that FedRCD's solvers also run (FedISHC, FedHC, HC-LiNGAM and HC) are by Chen et al.; [FedRCD](fedrcd.md) gives their references. GES and XGES, which every FedGES site runs, come from [causalbase](https://ptorrijos99.github.io/causalbase/citing.html), which has its own citation.
