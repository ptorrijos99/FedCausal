# Changelog

This project follows [Semantic Versioning](https://semver.org/). While the version is below 1.0, the public API may change between minor releases.

## 0.1.0

First public release: GES over discrete data, the FedGES federated loop with the structural fusion operators, the FedRCD family for continuous data, and a Flower transport for both. See the [documentation](https://ptorrijos99.github.io/fedcausal/) for what is in it.
